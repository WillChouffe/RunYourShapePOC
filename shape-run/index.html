    How to import into Strava
    1. Go to strava.com on a computer.
    2. Dashboard → My Routes → Create New Route.
    3. Click Import (upload icon) and pick the .gpx file.
    4. Save it, then open it in the Strava app to follow it while you run.

    The same file works with Garmin Connect (Courses → Import) and Komoot (Plan → Import GPX).

    ▶ ABOUT

    ZobRun turns your run into GPS art. Charity runs are popping up where every participant draws the same shape on the map, like La Grande Barre in Anglet, which raises funds for men's cancers (prostate and testicular).

    The goal: let anyone organise one. Pick a shape, a distance and a starting point, and get a route that's ready to run on Strava, Garmin or Komoot.
